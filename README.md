# To-understand-linear-and-circular-interpolation-of-industrial-manipulator-and-develop-a-program
To understand linear and circular interpolation of industrial manipulator and develop a program

# APPARATUS REQUIRED:

1.Industrial robotic manipulator

2.Robot controller

3.Teach pendant

4.Computer with robot programming/simulation software

5.End-effector / gripper

6.Work table or suitable workspace

7.Power supply and connecting cables

# ALGORITHM :

1. A Linear Interpolation

2.Start the robot system.

3.Initialize the robot and move it to the Home position.

4.Select the required tool/end-effector.

5.Teach and store the starting point P1.

6.Teach and store the ending point P2.

7.Select Linear Motion / Linear Interpolation.

8.Set the required robot speed and acceleration.

9.Command the robot to move from P1 to P2 in a straight-line path.

10.Execute the program.
